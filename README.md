<h3>A program for designing systems in order to understand and maintain code with greater ease. </h3>
<hr>
<h2>Controls:</h2> 
<ul>
<li>Arrow keys to pan around the workspace</li>
<li>Click on empty sections of the work space to pan around the workspace.</li>
<li>Click to select and deselect nodes</li>
</ul>

<h2>Tools:</h2> 
<ul>
<li>Draging nodes : click a node and move it </li>
<li>connecting nodes : press the add connection buttion and then select two nodes</li>
<li>disconecting nodes : press the remove connection buttion and then select two nodes</li>
<li>adding nodes: click the add node buttion (the node will be added in the middle of the workspace)</li>
<li>text : click the edit text button, click a node and start typing (remember to press enter)</li>
</ul>
